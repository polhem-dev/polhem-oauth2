# Contributing to Polhem.OAuth2

**English** | [繁體中文](CONTRIBUTING.zh-TW.md)

How changes reach the repository, and who merges them, is in the
[contributing guide of the polhem-dev organization](https://github.com/polhem-dev/.github/blob/main/CONTRIBUTING.md).
This page adds what is specific to this repository.

- Build and test with the commands under "Build and test" in [`.claude/CLAUDE.md`](.claude/CLAUDE.md).
- A change to a public document or an ADR updates both language versions
  ([ADR-002](docs/adr/adr-002-language-policy.md)).
