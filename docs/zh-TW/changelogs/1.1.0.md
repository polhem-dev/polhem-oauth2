# Polhem.OAuth2 1.1.0 — 發佈說明

[English](../../en/changelogs/1.1.0.md) | **繁體中文**

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[1.1.0]` 條目的詳細內容。

本版讓 .NET MAUI 應用程式可以登入，直接登入或經由應用程式自己的後端都可以。

## 新功能與變更

### .NET MAUI 應用程式登入

`AppOAuth2Client` 讓 Android、iOS 與 Mac Catalyst 上的 .NET MAUI 應用程式登入。它透過 `WebAuthenticator` 之類的委派開啟
登入頁，接受自訂 scheme 與 `https` 回呼網址，一律使用 PKCE，因此不需要 client secret。以 `fb<app id>` 回呼網址登入
Facebook 時，token 請求會補上 Facebook 要求的結尾斜線。見 [.NET MAUI 應用程式](../guides/maui.md)與
[ADR-006](../../adr/adr-006-app-sign-in.zh-TW.md)。

### 後端中轉

Polhem.OAuth2.AspNetCore 的 `AddOAuth2AppRelay`、`OAuth2AppRelayOptions`，以及 `OAuth2Manager.RedirectToAppAuthorization`、
`RedirectToAppAsync`、`RedeemAppCodeAsync`，讓應用程式經由自己的後端登入；provider 的 token 留在後端，應用程式拿到一個
只能用一次的 code。見[經由後端中轉登入](../guides/maui.md#經由後端中轉登入)。

### AOT 相容

Polhem.OAuth2 的 net10.0 組建標示為 AOT 相容，由 trim 與 AOT analyzer 檢查。

### Samples

OAuthMaui sample 示範 MAUI 應用程式登入，OAuthAspNetCore sample 新增中轉端點。見 [Samples](../guides/samples.md)。

### `LoopbackOAuth2Client.SignInAsync` 的文件

文件列出 `PlatformNotSupportedException`：iOS 上的預設瀏覽器會擲出這個例外。

### 修正

- Microsoft Entra ID provider 在個人 Microsoft 帳戶登入時也會填入 `UserName`：這類帳戶不傳 `name` claim，改由名字與姓氏組成
  （[#2](https://github.com/polhem-dev/polhem-oauth2/issues/2)）。

## 破壞性變更

無。
